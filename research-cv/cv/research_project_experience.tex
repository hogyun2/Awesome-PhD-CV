    {Stereo Vision-based Object Localization for Unmanned Surface Vehicles}
    {Samsung Heavy Industries}
    {2023}
    {
      \begin{cvitems}
        \item Developed \textit{Obcalizer}, a training-free stereo-vision framework for maritime metric object localization (detection, metric depth and 3D position estimation, and data association)
        \item Open-vocabulary detection with YOLO-World, box-level epipolar context matching for metric depth, and a depth-aware Kalman filter for tracking
        \item Lowest average 3D position error on real-world USV datasets (1.52\,m vs. 3.51\,m for the strongest baseline); runs at the 10\,Hz sensor rate on an NVIDIA Jetson AGX Orin
      \end{cvitems}
